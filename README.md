# AI-Based Smart Street Lighting

An AI-based smart street lighting system that automatically adjusts LED brightness according to environmental conditions.

## Project Overview

This project proposes a smart street lighting system that uses environmental sensor data and an AI-based decision-making approach to automatically control LED light intensity.

The system is designed to adjust lighting according to conditions such as light intensity and environmental factors, with the goal of supporting more efficient energy usage.

## Method

The project applies the ID3 Decision Tree algorithm to determine the appropriate LED brightness level based on environmental input data.

## Main Components

- LDR sensor
- DHT11/DHT22 sensor
- LED lighting
- Microcontroller
- ID3 Decision Tree
- Environmental data
